# Homebrew tap for Quarters

[Quarters](https://quarters.amithgc.com) is a minimalist home for terminal coding agents
(Claude Code, Codex, Gemini CLI, Antigravity, OpenCode, Copilot CLI, Devin, Aider).

```sh
brew install --cask amithgc/tap/quarters     # the Mac app
brew install amithgc/tap/quarters-server     # Linux: the server, used from a browser
```

The cask and formula here are updated by Quarters' release workflow; don't edit them by hand.
